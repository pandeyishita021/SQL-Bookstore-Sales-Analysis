# SQL-Bookstore-Sales-Analysis

##Project Overview
This project demonstrates SQL skills by analyzing a bookstore database containing information about books, customers, and orders. The objective is to answer real-world business questions using SQL while showcasing database querying, reporting, and analytical techniques.

The project covers customer analysis, book sales analysis, revenue insights, inventory tracking, and order reporting using MySQL.

##Business Objectives
- Analyze bookstore sales performance
- Understand customer purchasing behavior
- Track inventory availability
- Generate revenue reports
- Identify bestselling books
- Practice real-world SQL querying techniques

##Database Schema
The project consists of three relational tables:

##Books
Contains book details including:
- Book ID
- Title
- Author
- Genre
- Published Year
- Price
- Stock

##Customers
Contains customer information:
- Customer ID
- Name
- Email
- Phone
- City
- Country

##Orders
Stores transactional data:
- Order ID
- Customer ID
- Book ID
- Order Date
- Quantity
- Total Amount
